# 🏓 Pong Game (Python + Pygame)

A simple **Pong game** built with **Python** and **Pygame**, managed using the [uv](https://github.com/astral-sh/uv) package installer.  
Two players can play against each other using the keyboard, with a reset button to restart the ball.

---

## 🚀 Features
- Classic **2-player Pong gameplay**
- **Keyboard controls** for both players  
  - Player 1: `W` (up), `S` (down)  
  - Player 2: `↑` (up), `↓` (down)
- Score tracking for both players
- **"New Ball" button** to reset and launch the ball
- Built using **uv** for fast, modern Python dependency management

---

## 🛠️ Installation

Clone this repository:

```bash
git clone https://github.com/Manav010203/pong-game.git
cd pong-game
```
install dependencies using 
```uv sync```

Enjoy. :)
